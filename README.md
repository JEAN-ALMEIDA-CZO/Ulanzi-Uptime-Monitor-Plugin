# Ulanzi-Uptime-Monitor-Plugin
Uptime Monitor Estado e latência em tempo real no seu Ulanzi Deck. O Uptime Monitor acompanha qualquer site, API ou servidor diretamente numa tecla. Faz ping ao URL em intervalos, mostra a latência atual, um gráfico em tempo real das últimas verificações e a percentagem de disponibilidade — para detetar problemas num relance.
